# Curistro — Learning by Teaching

Curistro lets you learn by teaching an AI student. Explain a concept, answer its clarifying questions, and see how well it can apply what you taught.

Built by **Zhuoyan Yu** and **Xiongfeng Li** as team **AI Pathfinders** for the **NYU Shanghai Digital Innovation Challenge** (December 2024–April 2025). **Best Innovation Award.**

## Competition demo

The `dic-2025` tag preserves the competition demo's application code and functionality. Credentials and temporary files are excluded. The [main branch](https://github.com/zhuoyan-yu/curistro) contains the current version and setup instructions.

## Features

- Teaching conversations with streamed AI clarifying questions.
- Explain-back summaries from the AI student.
- Text-to-speech and recorded speech-to-text.
- Four diagnostic quiz dimensions, AI answer explanations, and adaptive recaps.
- A knowledge map connecting user-supplied related topics.
- Markdown and PDF session exports.

Quiz scores describe the **AI student's answers**.

## Running this version

The competition demo ran locally, with in-memory sessions and no accounts. This version uses its original API configuration and machine-specific audio setup. For a current installation, follow the instructions on [main](https://github.com/zhuoyan-yu/curistro).
